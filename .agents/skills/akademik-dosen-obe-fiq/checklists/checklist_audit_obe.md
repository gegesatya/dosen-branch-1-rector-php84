# Checklist Audit OBE

Gunakan checklist ini sebelum output akhir.

- [ ] Source-first dipatuhi: kurikulum, CPL, bahan kajian, mapping CPL ↔ MK faktual tidak dibuat ulang AI.
- [ ] Status sumber (provenance) jelas: FACTUAL, AI_PROPOSAL, MANUAL, APPROVED.
- [ ] CPMK hasil AI berstatus AI_PROPOSAL dan disetujui (APPROVED) sebelum menyusun Sub-CPMK.
- [ ] Sub-CPMK tidak kaku 1 pertemuan = 1 Sub-CPMK (dapat 1 Sub-CPMK untuk beberapa pertemuan).
- [ ] Kata kerja operasional Bloom C2–C6 proporsional sesuai karakter mata kuliah, semester, dan berprogresi (tanpa bobot numerik otomatis).
- [ ] Tidak ada label/kode Bloom (C2, C3, C4, dst.) yang tertulis eksplisit di dokumen output, kecuali diminta pengguna.
- [ ] Alignment Profil Lulusan → CPL → BK → MK → CPMK → Sub-CPMK → Aktivitas → Asesmen terjaga.
- [ ] Matriks relevan sudah tersedia.
- [ ] Hitungan 1 SKS = 45 jam = 2.700 menit sudah benar.
- [ ] TM/PT/BM sudah transparan dan mengikuti kebijakan kampus atau diberi catatan default.
- [ ] Total bobot penilaian = 100%.
- [ ] Bobot penilaian punya alasan logis, bukan asal rata.
- [ ] Penelitian dosen terintegrasi jika tersedia, atau berjalan tanpa integrasi penelitian dosen (tanpa konten/placeholder palsu pada dokumen final).
- [ ] Rubrik sesuai asesmen.
- [ ] Jika CPMK APPROVED diubah kembali, Sub-CPMK dan artefak turunannya ditandai memerlukan validasi ulang sebelum dapat dinyatakan final.
- [ ] Status dokumen jelas: Final, Draf Usulan Awal (AI_PROPOSAL), atau Disetujui (APPROVED).
- [ ] Acuan regulasi memakai Permendiktisaintek No. 39/2025 jo. No. 10/2026 (bukan Permendikbudristek No. 53/2023 yang sudah dicabut).
- [ ] Jika evaluasi ketercapaian CPMK: NBM, target ketercapaian klasikal, dan ambang kelulusan mata kuliah berasal dari data pengguna atau diberi label [ASUMSI DEFAULT - PERLU VALIDASI PRODI/SPMI].
