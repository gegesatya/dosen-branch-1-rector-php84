# Kalkulator SKS dan Bobot Penilaian

## A. Kalkulator SKS

Input wajib:
- jumlah SKS
- jumlah pertemuan efektif
- jenis mata kuliah: teori/praktikum/praktik/studio/proyek/lapangan/bauran
- kebijakan TM/PT/BM kampus jika ada

Rumus:
- Total jam = SKS × 45
- Total menit = SKS × 2.700
- Menit per pertemuan = Total menit / jumlah pertemuan efektif

Distribusi default teori bila kebijakan kampus tidak ada:
- Rasio TM:PT:BM = 50:60:60
- Total rasio = 170
- TM = total menit per pertemuan × 50/170
- PT = total menit per pertemuan × 60/170
- BM = total menit per pertemuan × 60/170

## B. Kalkulator bobot penilaian

Total bobot asesmen wajib 100%.

Rumus kerja:
Skor Bobot Sub-CPMK = Kontribusi CPL × Kompleksitas Bloom × Beban Waktu × Kompleksitas Bukti

Normalisasi:
Bobot Sub-CPMK = Skor Sub-CPMK / Total Skor semua Sub-CPMK × 100%

Bobot Bloom default:
- C4 = 1,00
- C5 = 1,15
- C6 = 1,30

Bobot bukti default:
- kuis/refleksi analitis = 0,80–1,00
- tugas analisis/studi kasus = 1,00–1,15
- presentasi/debat/evaluasi = 1,10–1,20
- proyek/desain/produk = 1,20–1,40
- artikel/proposal/portofolio komprehensif = 1,30–1,50

Setelah normalisasi, buat tabel pemeriksaan total 100%.
