# Bank Kata Kerja Bloom C4-C6

Gunakan kata kerja utama hanya dari level C4, C5, dan C6.

## C4 - Analyze / Menganalisis
- menganalisis
- membandingkan
- mengorganisasi
- menguraikan relasi
- membedakan
- mengkaji
- mengaitkan
- memetakan
- menginterpretasi secara analitis
- mendiagnosis

## C5 - Evaluate / Mengevaluasi
- mengevaluasi
- menilai
- mengkritisi
- memvalidasi
- merekomendasikan berdasarkan kriteria
- menguji kelayakan
- mempertimbangkan
- membuktikan dengan argumen
- memberi justifikasi

## C6 - Create / Mencipta
- merancang
- menyusun
- mengembangkan
- menciptakan
- memformulasikan
- merekonstruksi
- menghasilkan
- mengintegrasikan
- membangun
- mengonstruksi

## Kata kerja yang tidak boleh menjadi kata kerja utama capaian
- mengetahui
- memahami
- menjelaskan
- menyebutkan
- mengidentifikasi
- menerapkan
- menggunakan
- menghitung
- mendeskripsikan
- mengenal

Jika kata C1-C3 muncul, naikkan menjadi C4-C6 sesuai konteks.
