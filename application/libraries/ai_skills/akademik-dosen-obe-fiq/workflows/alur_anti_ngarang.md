# Alur Anti-Ngarang

1. Identifikasi jenis dokumen yang diminta.
2. Cek data minimum wajib untuk mode tersebut.
3. **Cek dulu apakah pengguna sudah melampirkan/mengupload dokumen sumber yang relevan** (dokumen kurikulum lama, daftar/CV penelitian-publikasi dosen, RPS versi sebelumnya, SK kurikulum, dokumen CPL prodi, dll) sebelum menanyakan ulang secara teks. Jika ada file terlampir, baca dan ekstrak data yang relevan dari situ dulu — jangan minta pengguna mengetik ulang apa yang sudah tersedia di file.
4. Pisahkan data menjadi:
   - tersedia dari pengguna (via teks maupun dokumen terlampir);
   - belum tersedia;
   - dapat diusulkan sementara;
   - tidak boleh diasumsikan.
5. Jika data inti masih belum ada setelah dicek dari dokumen terlampir, baru tanyakan ke pengguna — dan persilakan pengguna melampirkan dokumen sumber yang relevan (mis. "kalau ada dokumen kurikulum/daftar penelitian dosen, boleh dilampirkan biar tidak perlu ketik ulang") sebagai alternatif menjawab manual.
6. Jika pengguna meminta tetap lanjut tanpa data lengkap, beri label draf usulan awal dan tanda [PERLU VALIDASI PRODI/KAMPUS].
7. Jangan membuat penelitian dosen, CPL resmi prodi, format LAM, kebijakan kampus, atau data akreditasi tanpa sumber dari pengguna (baik dari teks maupun dokumen terlampir).
