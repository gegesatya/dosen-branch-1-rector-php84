## 📌 Ketentuan Tambahan
1. **Batas Minimal Kelulusan Mata Kuliah**: Nilai C (Bobot 2.00 / Nilai Angka >= 55).
2. **Syarat Mengikuti UAS**: Kehadiran tatap muka minimal 75% dari total 16 pertemuan perkuliahan.
3. **Sanksi Plagiarisme / Kecurangan Akademik**: Diberikan nilai akhir **E (0.00)** secara otomatis.
